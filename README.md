# YourHome.asia

Property portal for Cambodia – apartments, houses, condos and rooms for rent and sale in Phnom Penh.
Free listings for owners and agents, TOP placements, advertiser dashboard with statistics.

Live: https://yourhome.asia

- Static site (index.html, app.js, i18n.js, styles.css, header.css), hosted on Vercel.
- Data and login: Supabase (`yh_` tables).
- Languages: English, Khmer, Chinese, French, Thai.
